# HDU-Computer_Network_Experiment
### 2024在HDU学习期间的计网实验汇总

2024年**网安院**计网实验共有11个，10个在Cisco Packet Tracer上搭建网络拓扑，1个关于SOCKET通信的实验。  

Cisco的实验初入手有点困难，学交换机路由器配置就需要些时间，但是熟悉了之后其实都大差不差。  

剧透一下大三上如果修读网安技的话会有4个老师总计快有20多个实验，其中高梦洲老师的实验还是Cisco，量也很多有点复杂，建议先通过大二计网把实验部分搞明白，大三上面对网安技更从容一些。

## 目录结构说明
| 文件夹 | 内容描述 |
| :--- | :--- |
| **📁 实验** | 包含具体的实验代码实现（如 Socket 编程、协议分析等） |
| **📁 实验任务** | 老师下发的实验要求与说明文档 |
| **📁 实验报告及模板** | 最终提交的报告正文及可复用的格式模板 |
| **📁 一些课内资料** | 课程 PPT、复习笔记等辅助资料 |
