# HDU-Computer_Network_Experiment

> **杭州电子科技大学（HDU) - 计算机网络实验课程项目仓库**

本项目用于存放 2025 学年《计算机网络实验》课程的相关实验、报告。对实验内容要求进行了精确的分区，实验源.pkt文件也进行了对应的保存，实验运行环境是Cisco Packet Tracer 8.2.2，由校方提供。

---

### 2025在HDU学习期间的计网实验汇总

2025年**网安院**计网实验共有11个，10个在Cisco Packet Tracer上搭建网络拓扑，1个关于SOCKET通信的实验。  

Cisco的实验初入手有点困难，学交换机路由器配置就需要些时间，但是熟悉了之后其实都大差不差。  

剧透一下大三上如果修读网安技的话会有4个老师总计快有20多个实验，其中高梦洲老师的实验还是Cisco，量也很多有点复杂，建议先通过大二计网把实验部分搞明白，大三上面对网安技更从容一些。
